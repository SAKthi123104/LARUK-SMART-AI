# Laruk – Personalised AI Tool 🤖✨

## 📌 Overview
Laruk is a personalised AI companion built to act as:
- 💬 Chat + Code Assistant  
- 🛠 Project Helper  
- 🧠 Memory System  

The vision behind Laruk is to go beyond a normal chatbot and create a tool that feels alive, remembers context, and supports real‑life coding & project workflows.

---

## ⚙️ Tech Stack
- **Backend:** Flask (Python)  
- **Database:** MySQL  
- **Frontend:** React + Tailwind CSS  
- **Deployment:** ngrok (for tunneling & public access)  
- **AI Models:** Offline integration (no external API dependency)

---

## 🎯 Features
- 💬 **Chat + Code Assistant** – Helps with coding queries, debugging, and explanations  
- 🛠 **Project Helper** – Tracks goals, challenges, and tasks  
- 🧠 **Memory System** – Remembers user preferences & adapts responses  
- 🌐 **Frontend + Backend Integration** – Smooth communication between UI & Flask server  
- 🔒 **Offline AI Companion** – Designed to work without constant internet/API dependency  

---

## 🚀 Learning Outcomes
- Flask backend development & Jinja2 debugging  
- MySQL database integration  
- Modern UI design with React + Tailwind CSS  
- Deployment workflows with ngrok  
- Building personalised AI tools with memory systems  

---

## ✨ Impact
Laruk is not just a project — it’s a **next‑level AI companion** that showcases:
- Full‑stack development skills  
- Creativity in UI/UX  
- Innovation in offline AI integration

## 🔧 Setup & Installation
```bash
# Clone the repo
git clone https://github.com/your-username/laruk.git

# Navigate to project folder
cd laruk

# Backend setup
pip install -r requirements.txt
python app.py

# Frontend setup
npm install
npm run dev

```
